# エッグチ - 育成ペットゲーム

完全オリジナルの携帯育成ペット風Webアプリゲームです。スマホ（特にiPhone）に最適化されています。

## 🎮 遊び方

### 基本操作

ゲーム画面には4つのメインボタンがあります：

- **ごはん（🍚）**: ペットに食べ物をあげます。空腹を減らし、元気とごきげんを上げます
- **あそぶ（🎮）**: ミニゲームで遊びます。ごきげんが上がりますが、元気を消費します
- **そうじ（🧹）**: 汚れを掃除します。清潔度を回復します
- **メニュー（📋）**: ステータス確認、設定、ケアなどができます

### ステータス

ペットには5つの主要なステータスがあります（0〜100）：

- **空腹**: 時間経過で増加。高すぎると病気になります（ごはんで回復）
- **元気**: 時間経過で減少。低すぎると病気になります（ごはんや睡眠で回復）
- **ごきげん**: 時間経過で減少。低いと進化に悪影響（ごはんや遊びで回復）
- **清潔**: 時間経過で減少。低すぎると病気に、汚れが出現します（そうじで回復）
- **年齢**: 時間経過で増加（分単位）

### 時間経過

- ゲームはリアルタイムで進行します（1分 = 1分）
- アプリを閉じている間も時間は進み、ステータスが変化します
- 最大48時間分の不在時間を計算します

### 状態アイコン

画面上部に表示されるアイコンは、ペットの状態を示します：

- 🍽️ 空腹（空腹度が高い）
- ⚡ 元気不足（元気が低い）
- 😊 ごきげん低下（ごきげんが低い）
- ✨ 汚れ（清潔度が低い）
- 🤒 病気（要：げんきぐすり）
- 💤 睡眠中

### ミニゲーム

**タイミングゲーム**: 移動するバーが中央の緑ゾーンに来たタイミングでタップします
- パーフェクト: ごきげん +20
- いいかんじ: ごきげん +15
- ざんねん: ごきげん +5

**どっちゲーム**: 左右どちらかを当てるシンプルなゲームです
- 正解: ごきげん +20
- 不正解: ごきげん +5

### バッド状態

**病気**:
- 空腹が80以上、元気が20以下、清潔が20以下のうち2つ以上該当すると病気になる可能性があります
- 病気の間はステータスが悪化します
- メニューから「げんきぐすり」を使って治療してください

**汚れ**:
- 清潔度が30以下になると、画面に💩が出現します
- そうじボタンで掃除してください

### 睡眠

- メニューから「ねる / おこす」を選択して睡眠モードに入れます
- 睡眠中はステータスの悪化速度が30%に軽減されます
- 画面が暗くなり、💤マークが表示されます

## 🌟 成長と進化

ペットは年齢とケア品質に応じて進化します。

### 成長段階

1. **タマコ（卵）**: 0〜10分
   - 卵の状態。揺れるアニメーション

2. **コロリン（幼体）**: 10分〜
   - 初めての進化。小さくて丸い生き物
   - **進化条件**: 年齢10分以上、ケア品質50以上、ミス5回以下

3. **成体（3種類）**: 60分〜

   **ハピネル（最良）**:
   - 愛情いっぱいに育った理想の姿
   - 翼があり、ハート模様
   - **進化条件**: 年齢60分以上、ケア品質80以上、ミス3回以下

   **ノマール（普通）**:
   - 平凡だけど愛らしい成体
   - ドット模様
   - **進化条件**: 年齢60分以上、ケア品質50以上、ミス10回以下

   **グルーモ（低品質）**:
   - ケア不足で少し不機嫌な姿
   - ずんぐりした体型
   - **進化条件**: 年齢60分以上（ケア品質やミス回数は問わず）

### ケア品質

ケア品質は以下の要素の平均値です：
- 空腹の良好度（100 - 空腹度）
- 元気
- ごきげん
- 清潔度

ケア品質が30以下の状態が続くと、ケアミス回数が増えます。

### 進化演出

進化時には画面がフラッシュし、効果音が鳴ります。

## 💾 セーブの仕組み

### 自動セーブ

- すべてのアクション（ごはん、あそぶ、そうじなど）の後に自動的にセーブされます
- セーブデータはブラウザのlocalStorageに保存されます
- セーブ内容:
  - 全ステータス（空腹、元気、ごきげん、清潔度）
  - 状態（病気、睡眠、汚れレベル）
  - 成長情報（年齢、進化段階）
  - ケア品質、ミス回数
  - 最終更新時刻

### 不在時間の処理

- ゲームを開いた時、最終更新時刻から現在までの経過時間を計算します
- 最大48時間分の経過を適用します（それ以上は切り捨て）
- 睡眠中の場合、ステータス悪化速度は30%に軽減されます

### データリセット

- メニューから「リセット」を選択すると、すべてのデータが削除され、最初からやり直せます
- この操作は取り消せません

## 🔧 設定

メニュー画面から以下の設定ができます：

- **音量**: スライダーで0〜100%に調整できます
- **ミュート**: ON/OFFで効果音を完全にミュートできます

## 🌐 GitHub Pagesでの公開

このゲームはGitHub Pagesで公開できます。

### 公開手順

1. このリポジトリをGitHubにプッシュ
2. リポジトリの Settings → Pages に移動
3. Source を「main」ブランチの「/ (root)」に設定
4. 「Save」をクリック
5. 数分後、`https://[ユーザー名].github.io/[リポジトリ名]/` でアクセス可能になります

### 必要なファイル

すべてのファイルがリポジトリのルートディレクトリにあります：
- index.html（エントリーポイント）
- style.css
- script.js
- data/species.json
- data/items.json

外部ライブラリやCDNは使用していないため、追加の設定は不要です。

## 🎯 開発方針

- **MVP優先**: まず基本機能を確実に動作させる
- **スマホファースト**: iPhone縦画面を最優先
- **完全オリジナル**: 既存作品の模倣を避け、独自の名称・デザイン・システムを採用
- **シンプル**: 外部依存なし、純粋なHTML/CSS/JSのみ
- **堅牢性**: 長期不在や異常値に対する防御機構

# ミルモノ - 不気味かわいい育成ペット

影から生まれた小さな生き物「ミルモノ」を育てる、オリジナル育成ペットゲームです。
レトロな携帯液晶風デザインで、スマホ（特にiPhone）に最適化されています。

## 🌙 世界観

ミルモノは影の中から生まれる不思議な生き物。
常に何かを見つめ、ゆっくりと揺れながら成長します。
可愛いけれど、少し不思議で不穏な雰囲気を持っています。

- 目が増えたり減ったり
- 影が伸びたり縮んだり
- 光を宿したり闇を深めたり

## 🎮 操作方法

### 基本操作（4ボタン固定）

画面下部に4つのボタンがあります：

- **ごはん（🍚）**: 空腹を減らします。選べる食べ物は3種類
  - カゲのしずく: 基本の食事
  - ツキのこな: きげんも上がる
  - ヨルのアメ: 元気も回復

- **あそぶ（🎮）**: 5秒以内の超短いミニゲーム
  - 移動するバーを真ん中で止めるタイミングゲーム
  - 成功するときげんが大きく上がる

- **そうじ（✨）**: 清潔度を最大に戻します
  - 1タップで完了

- **メニュー（📋）**: ステータス確認・設定・ケア
  - ステータス詳細を見る
  - ヒカリのきり（薬）を使う
  - 音量調整・ミュート
  - リセット

### ステータス（0〜100）

5つのステータスがあります：

- **空腹**: 時間経過で増加（5分で+6）。高いと体調不良に
- **元気**: 時間経過で減少（5分で-4）。低いと体調不良に
- **きげん**: 時間経過で減少（5分で-2）。進化に影響
- **清潔**: 時間経過で減少（5分で-3）。低いと体調不良に
- **なつき**: 時間経過でゆっくり減少（5分で-1）。軽めに効く

### 状態アイコン

画面上部に表示されるアイコンで、ミルモノの状態がわかります：

- 🍽 空腹（空腹度60以上）
- 💤 元気不足（元気30以下）
- 😢 きげん低下（きげん30以下）
- 💩 汚れ（清潔度30以下）
- 🤒 体調不良（要：ヒカリのきり）

### 時間経過

- ゲームはリアルタイムで進行します
- アプリを閉じている間も時間は進みます
- 最大24時間分の不在時間を計算します
- 長時間放置しても詰まりません（後述）

## 🌟 成長と進化（5分岐）

ミルモノは年齢とケアの傾向で成長します。

### 成長段階

**1. カゲダマ（影玉）- 0〜5分**
- 影の中から生まれた小さな玉
- 目はまだ開いていません
- ゆっくりと揺れています

**2. ミルコ（見る子）- 5〜30分**
- 目を開けて何かを見つめています
- 2つの目で周囲を観察
- この段階でケアの傾向が決まります

**3. 成体（5種類）- 30分以降**

ケアの傾向によって5種類に分岐します：

#### ヒカルモノ（清潔重視）
- **進化条件**: そうじを最も多く行う
- **見た目**: 光を宿す、澄んだ目、光の粒が周囲を回る
- **特徴**: きらきらと輝く清らかな存在

#### アソブモノ（遊び重視）
- **進化条件**: あそぶを最も多く行う
- **見た目**: 目が4つに増える、元気な色合い
- **特徴**: 活発で好奇心旺盛な姿

#### カゲモノ（放置気味）
- **進化条件**: 10分以上放置した時間が最も多い
- **見た目**: 影が濃く長い、目が1つ、暗い色合い
- **特徴**: 静かで少し寂しげな存在

#### マンプクモノ（ごはん重視）
- **進化条件**: ごはんを最も多くあげる
- **見た目**: 丸々とした体、満足そうな目
- **特徴**: 穏やかで満ち足りた姿

#### フツウモノ（バランス型）
- **進化条件**: すべてのケアをバランスよく行う
- **見た目**: 標準的な姿、2つの目
- **特徴**: 調和の取れた成体

### ケア傾向の判定

進化時（30分到達時）に、以下のカウントを比較します：

- ごはん回数（feedCount）
- あそぶ回数（playCount）
- そうじ回数（cleanCount）
- 放置時間（10分以上放置した合計時間）
- バランス（最もバランスが取れている場合）

最も多い項目に対応する成体に進化します。

### 進化演出

進化時には以下の演出があります：
- 画面がフラッシュ
- 効果音が鳴る
- メッセージが表示される

## ⚠️ 体調不良について

以下の条件で体調不良になる可能性があります：

- 空腹が80以上
- 元気が20以下
- 清潔度が20以下

上記のうち2つ以上が該当すると、30%の確率で体調不良になります。

**治療方法**:
- メニューから「ヒカリのきりを使う」を選択
- 体調が回復し、元気が+30されます

## 💾 セーブの仕組み

### 自動セーブ

すべてのアクション後に自動的にセーブされます：
- ごはん、あそぶ、そうじ
- 薬の使用
- 進化

**セーブ内容**:
- 全ステータス（空腹、元気、きげん、清潔度、なつき）
- 体調不良フラグ
- 年齢、進化段階
- ケア傾向カウント（ごはん、あそぶ、そうじ、放置時間）
- 最終更新時刻

### 不在時間の処理

- ゲームを開いた時、最終更新時刻から現在までの経過時間を計算
- 最大24時間分の経過を適用（それ以上は切り捨て）
- ステータスは時間経過に応じて変化

### データリセット

メニューから「リセット」を選択すると、すべてのデータが削除され、最初からやり直せます。

## 🛡️ 放置ペナルティが軽い理由（復帰可能）

このゲームは「放置しても詰まない」設計です：

### 1. 死亡・消滅なし
- ステータスが0になっても、ミルモノは消えません
- いつでも回復行動で戻せます

### 2. 復帰しやすい
- ごはんをあげれば空腹は回復
- そうじをすれば清潔度は最大に
- 体調不良も薬で即回復

### 3. 放置も進化ルートの一つ
- 放置が多いと「カゲモノ」に進化
- これも正規の進化ルートです
- 悪い結果ではなく、一つの個性

### 4. 時間制限に上限あり
- 不在時間は最大24時間まで計算
- 長期間放置しても「24時間分の悪化」で止まる
- 極端な状態にはなりません

### 5. ゆっくりな悪化速度
- 5分で空腹+6、清潔-3など、ゆるやか
- 少し放置しただけでは大きな影響なし

**結論**: ライフスタイルに合わせて、マイペースに遊べるゲームです。
